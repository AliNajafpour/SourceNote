# Changelog

## 1.1.0 — 2026-10-14

- Windows installer with a stable per-user install folder, Start menu icon, optional desktop shortcut, and uninstall support.
- New installers upgrade the existing installation while retaining notes and backups; older installers cannot downgrade it.
- Automatic GitHub release checks at launch and every six hours, with a notification and a user-controlled download step.
- Installed version and manual update check in the calendar sidebar.
- Prerequisite checks for .NET Framework and Microsoft WebView2 Runtime before installation.
- Installer upgrade/uninstall checks and validation of release versions and download ownership.

## 1.0.0 — 2026-10-07

- First Windows release with an offline daily board.
- General and day-specific sticky notes and checklists, with direct creation buttons.
- Individual task dates, drag-to-date scheduling, and shared completion state.
- Note minimization, colors, reordering, duplication, and delete undo.
- Search, grid/list layouts, and persistent light/dark themes.
- Local saving, JSON export, and Windows backup import with a copy of previous notes.
- Browser version, Windows build script, and model/native regression checks.
