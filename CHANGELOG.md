# Changelog

## 1.0.0 — 2026-10-07

- First Windows release with an offline daily board.
- General and day-specific sticky notes and checklists, with direct creation buttons.
- Individual task dates, drag-to-date scheduling, and shared completion state.
- Note minimization, colors, reordering, duplication, and delete undo.
- Search, grid/list layouts, and persistent light/dark themes.
- Local saving, JSON export, and Windows backup import with a copy of previous notes.
- Browser version, Windows build script, and model/native regression checks.
